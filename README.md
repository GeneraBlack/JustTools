# ⚒️ Just Tools

**A comprehensive tool expansion mod for Minecraft 1.21.1 (NeoForge)**

Just Tools adds new tool types, new material tiers, a tool hardening system, and 11 unique upgrade plates — all designed to extend your mining experience without changing Minecraft's core feel.

---

## ✨ Features

### 🔨 New Tool Types

- **Hammers** — 3×3 area pickaxes that mine a full wall of stone in one swing. Available for all tiers from Wood to Netherite.
- **Excavators** — 3×3 area shovels for clearing dirt, gravel, and sand in huge swathes.
- **Paxels** — The ultimate multi-tool combining Pickaxe + Axe + Shovel + Hoe into one item. Right-click to strip logs, flatten paths, till soil, and more.

### ⛏️ New Material Tiers

- **Copper Tools** — A full tool set (Sword, Pickaxe, Axe, Shovel, Hoe, Hammer, Excavator, Paxel) using Copper Ingots. Sits between Stone and Iron with 190 durability and fast mining speed.
- **Deepslate Tools** — Crafted from Cobbled Deepslate. Stone-level mining with 320 durability — a durable early-game alternative.

### 🛡️ Tool Hardening System

The **Hardening Station** is a new workstation block that lets you reinforce any tool into its **Hardened** variant:

- **~2.5× to 4× durability boost** (e.g., Diamond Pickaxe: 1,561 → 4,000)
- **Increased mining speed and attack damage**
- **Higher enchantability**
- **Fully repairs the tool and resets anvil penalty** — no XP cost!
- Works on **all vanilla tools** + all JustTools items (Copper, Deepslate, Hammers, Excavators, Paxels)

The Hardening Station also serves as a **free repair station**:
- Repair with raw materials (50% durability per item, 0 XP)
- Combine duplicate tools (merges enchantments + 12% bonus durability)

### 🔧 11 Upgrade Plates

Install upgrade plates in the Hardening Station to add permanent abilities to any tool:

| Plate | Effect |
|:------|:-------|
| **Hardening Plate** | Upgrades to Hardened variant or fully repairs |
| **Depth Drill Plate** | Hammers/Excavators mine 3×3×2 (18 blocks per swing) |
| **Soul Repair Core** | Passive auto-repair (1 durability / 5s) + XP mending |
| **Lava Seal Plating** | Tool is fireproof and floats in lava |
| **Redstone Turbine** | +35% mining speed + Haste on continuous mining |
| **Wind Core Plate** | Removes underwater and mid-air mining penalties |
| **Thermal Core Plate** | Auto-smelts mined drops (ore → ingots, sand → glass) |
| **Reinforced Frame** | 50% chance to negate durability loss |
| **Amethyst Shield** | Prevents tool from breaking (stops at 1 durability) |
| **Photosynthesis Plate** | Repairs in sunlight or on grass/moss |
| **Magnetic Vacuum** | Mined items go directly into your inventory |

All upgrades stack — combine them freely to create your perfect tool!

## 📦 Installation

1. Install [NeoForge](https://neoforged.net/) for Minecraft **1.21.1**
2. Download the latest `justtools-x.x.x.jar` from [CurseForge](https://curseforge.com) or [Modrinth](https://modrinth.com)
3. Place the `.jar` file in your `mods/` folder
4. Launch Minecraft!

**No dependencies required** — Just Tools is fully standalone.

---

## 🎮 Getting Started

1. **Craft Copper or Deepslate tools** using their respective materials in standard tool recipes
2. **Craft a Hammer, Excavator, or Paxel** — Hammers use 5 ingots + 2 sticks, Paxels combine a Pickaxe + Axe + Shovel + Stick
3. **Build a Hardening Station** to upgrade and maintain your tools
4. **Craft Upgrade Plates** and install them to add special abilities
5. **Harden your tools** with a Hardening Plate for massively increased durability and stats

---

## 📋 Crafting Recipes

All recipes are viewable in-game via JEI/REI or the recipe book. Key recipes:

- **Hardening Station**: Crafted with Iron Ingots, Obsidian, and a Crafting Table
- **Hammers**: 5× material + 2× sticks (T-shape pattern)
- **Excavators**: 3× material + 2× sticks (shovel-like with wider head)
- **Paxels**: Pickaxe + Axe + Shovel + Stick
- **Upgrade Plates**: Each uses unique thematic materials (Echo Shards, Breeze Rods, Amethyst Shards, etc.)
