# ⚒️ Just Tools — Tool Expansion Done Right

**Just Tools** adds 110+ new items to Minecraft without changing the game's core feel. New tool types, two new material tiers, a powerful tool hardening system, and 11 unique upgrade plates that let you customize any tool.

---

## 🔨 New Tool Types

### Hammers — 3×3 Area Pickaxes
Mine a full 3×3 wall of stone in one swing! Available for every tier from Wood to Netherite. Only uses 1 durability per swing, regardless of how many blocks are broken.

### Excavators — 3×3 Area Shovels
Clear dirt, gravel, sand, and soul sand in massive 3×3 swathes. Perfect for terraforming and clearing land.

### Paxels — The Ultimate Multi-Tool
One tool that does it all: Pickaxe + Axe + Shovel + Hoe. Right-click to strip logs, flatten paths, scrape oxidation, remove wax, till soil, and extinguish campfires.

---

## ⛏️ New Materials: Copper & Deepslate

- **Copper Tools** — Fast mining speed (5.0), high enchantability (13), 190 durability. A great mid-tier option using those stacks of copper you've been hoarding!
- **Deepslate Tools** — Tanky early-game tools with 320 durability. Crafted from Cobbled Deepslate.

Both tiers include the full tool set: Sword, Pickaxe, Axe, Shovel, Hoe, Hammer, Excavator, and Paxel.

---

## 🛡️ Tool Hardening Station

A brand new workstation that lets you **reinforce any tool** into a Hardened variant:

- **2.5× to 4× durability boost** — Diamond Pickaxe goes from 1,561 to 4,000!
- **Better speed, damage, and enchantability**
- **Free repairs** with raw materials (50% per item, 0 XP cost)
- **Tool combining** that merges enchantments + grants 12% bonus durability
- **Resets anvil penalty** on every operation — no more "Too Expensive!"

Works on all vanilla tools AND all JustTools items.

## 🔧 11 Upgrade Plates

Install upgrades in the Hardening Station to permanently enhance any tool:

| Upgrade | What it does |
|:--------|:-------------|
| 🛡️ **Hardening Plate** | Upgrades to Hardened variant or fully repairs |
| ⛏️ **Depth Drill** | Hammers/Excavators mine 3×3×2 (18 blocks!) |
| 💜 **Soul Repair Core** | Auto-repair + XP mending |
| 🔥 **Lava Seal** | Fireproof — floats in lava |
| ⚡ **Redstone Turbine** | +35% speed + Haste on mining streaks |
| 💨 **Wind Core** | No underwater or mid-air mining penalty |
| 🌋 **Thermal Core** | Auto-smelts drops (ore → ingots!) |
| 🔩 **Reinforced Frame** | 50% chance to negate durability loss |
| 💎 **Amethyst Shield** | Tool never breaks (stops at 1 durability) |
| 🌿 **Photosynthesis** | Repairs in sunlight or on grass |
| 🧲 **Magnetic Vacuum** | Drops go straight to inventory |

**All upgrades stack!** Create the ultimate tool by combining them.
